## Application mapping

Delivery profile (declared in the adoption record): `state = none`, `packaging = single-file`, `store = none`, `identity = none`, `network = none`, `compute = interactive`; localization `scope = []`. The interface is English only. The multi-calendar readout (`src/calendars/**`, `src/chrono/**`, `src/temporal/**`) is domain computation over DATA, which C-44 places outside localization; `Intl.DateTimeFormat` with an explicit calendar is used as a calendar engine, not as a locale formatter. No platform ports. Bindings: `typescript:application`, `python:tooling`.

Role mapping (responsibility-named directories; roles are not directory names). `tools/check_standards.py` holds this table in code; a `src/<domain>/` directory it does not know is reported as `UNMAPPED-DOMAIN`.

| Role | Paths |
|---|---|
| VIEW | `src/*.ts` (top-level render and picker modules only), `index.html`, `src/style.css` |
| CONTROLLER | unmapped (render modules call PURE directly) |
| STATE | unmapped (selection state is in-memory in the render modules; `location.hash` carries what must survive a reload) |
| PURE | `src/entity/**`, `src/dataset/**`, `src/research/**`, `src/focus/**` |
| PURE-CORE | `src/calendars/**`, `src/chrono/**`, `src/temporal/**` |
| DATA | `src/data/**` (generated by `tools/build_data.py`), `schemas/**` |
| PLATFORM-PURE, PLATFORM-AMBIENT, MODEL, REMOTE | unmapped (no ports in this profile) |
| tooling class | `tools/**` (Python), `scripts/*.mjs` |

Commands are the repository's actual scripts. "Automated" runs in CI through `npm run build`, the e2e job and the dataset job (`python tools/validate.py`, `python tools/check_regenerated.py`); "manual-review" is checked in architecture and compliance reviews until the listed exception closes.

## Extensions

Application-level conventions that are not hub rules and stay here:

- App and dataset are versioned independently (four-part app version, dataset semver with schema version); `docs/DATASET-CHANGELOG.md` and `CHANGELOG.md`.
- Slug convention: `docs/SLUG-CONVENTION.md`.
- Dataset content proposals read `docs/gap-analysis-v2.1.0.md` first; schema fields unusable until the Python builder is extended are listed there.
- Research and sourcing notes under `docs/*-research.md` and `docs/sourcing-notes.md` are DATA provenance, not code policy.
