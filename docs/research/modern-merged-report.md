## Method

- Duplicate test: case-folded + diacritic-folded + punctuation-folded match on name or any alias, start years within 25 years, and compatible top-level region (`global` is compatible with every region). The region guard is what keeps Alexandria, Egypt distinct from Alexandria, Virginia.
- Within-batch ties keep the row with the longer summary.
- Parent hints resolve in this order: curated geographic override, existing entity (exact, then parenthetical-stripped name/alias), batch row being created in this run, then split of compound hints ("France and Germany"), then the nearest existing ancestor.
- Ids are `<resolved parent id>.<suggested_id_slug>`; event numerals stay as digits (e.g. `war-of-1812`, `september-11`).
- No uncertainty or bounds fields are emitted.
